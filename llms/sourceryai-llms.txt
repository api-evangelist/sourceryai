# Sourcery.AI

> Sourcery is an AI-powered code review platform for teams shipping large volumes of AI-generated and human-written code. It provides automated pull-request reviews (summaries, diagrams, line-by-line suggestions), continuous security scanning (SAST, SCA, secrets, IaC, license detection), team analytics, and real-time in-IDE feedback across GitHub, GitLab, VS Code, Cursor, and JetBrains IDEs. Sourcery is a Techstars-backed company and is SOC 2 and GDPR compliant. There is no public REST/GraphQL developer API; the product is consumed through its Git and IDE integrations, a GitHub Action, and open-source Python CLIs.
